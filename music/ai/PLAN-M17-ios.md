- Keep the existing library UI, OneDrive registration and cloud data. The native session must own continuous cellular playback while locked and play complete downloads offline. Judge the MP3 joins against the listener’s own files.
- **Gate 1 listening preference (2026-11-24).** Honor valid declared encoder delay or padding once. Otherwise, on decoded MP3 audio, trim consecutive quiet frames up to 150 ms at the end and 35 ms at the start. An above-threshold sample in either stereo channel stops the scan. The probe uses −80 dBFS. The listener accepts losing this bounded portion of an intentional fade. If either edge at a join actually used the fallback trim, audition a 2 ms linear overlap. Keep untrimmed and trimmed hard-cut references for comparison. A join between two untouched edges has no overlap.
- When a playlist edit removes the playing occurrence, **finish the song, then play the next surviving track**. Apply this rule to both players in phase 5.
- **Cellular preload has a hard ceiling of 4 MB (4,000,000 bytes) for the single speculative successor.** Allow the prepared prefix of an MP3 recording to play while Swift obtains a fresh raw download URL, which can take 5–10 seconds. Retries, metadata ranges in the media object, discarded responses and cancellation overshoot all count. If the reference join cannot be achieved inside the cap, the prototype fails.
- Incomplete pins may resume when the app is reopened. Use foreground transfers and keep the playback session independent of pinning.
- Use a fresh GPT-6.2-Sol reviewer at High reasoning effort wherever the milestone process calls for Claude. The execution instructions above are reproduced verbatim.

**Measuring speculative reads.** Compare successor body bytes at enqueue, the transition and after skip. Keep the accounting for the full speculative preparation, including cancelled work still draining, rereads of the same range and media headers/tails fetched from the file. **Enforcing the cap.** Measure the preferred buffer required to cover the observed 5–10 second URL-renewal delay, starting with 12 seconds of playable audio as a trial. Prefer enough contiguous decodable audio at the start of the successor to cover that delay plus decoder startup, within the hard 4 MB cap. Report actual playable seconds for the test MP3s. Bytes buffered at the end of a file do not extend the runway at its start. A duration setting alone cannot enforce a byte ceiling. For unpinned cellular playback use a native asset resource loader backed by metered URLSession reads unless the chosen transport exposes an equivalent enforceable cap. Keep both current and successor traffic under native ownership so a Wi-Fi-to-cellular change cannot leave an unmetered successor running. The original gate used the same cap on both routes. Build 17 keeps that cap for narrow speculative reads and admits a separate unmetered-Wi-Fi-only prefix within the listener’s rolling 6 MB window. Only one successor may fetch at a time. Reserve each range against the remaining allowance before issuing the request, and stop admitting new speculative requests when the allowance runs out. Replacement/cancellation drains the old request before starting another. Do not reset the budget on retry, a redundant preparation of the same upcoming occurrence, or a URL change. Release the speculative limit for *demand* reads when the item becomes current. A pinned file uses local bytes.

Give AVFoundation a private media scheme. Serve content-info and range requests from a per-recording sparse buffer that the player also consumes after promotion. Check offsets, object version and total length. Accept valid 206 responses matching the requested range. Accept a 200 for an entire file only when starting at zero and the identity and known complete length fit the remaining allowance. Reject ignored/nonmatching ranges or unbounded responses at the headers, count any bytes already transferred, and disable speculation on that source if it cannot be bounded. Never append a 200 body at a nonzero offset. Test matching 206 responses, 416, retries, cancellation and refreshed URLs. The listener waived a dedicated experiment with a server that ignores Range. Keep the inexpensive response validation. Reusing the prepared prefix on promotion must produce zero duplicate prefix fetches in the valid same-version range case. Capture actual transferred body bytes independently of the buffer high-water mark. If transport behavior or in-flight overshoot makes the hard ceiling unverifiable or exceeds it, that path fails.
